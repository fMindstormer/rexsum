VIN (vehicle identification number), checked by HTML alone

This page contains no script. The field's pattern attribute holds a 7,025-character regular expression that the browser's own form validation runs on every change.

Accepted
17 digits or capitals, no I, O or Q; the 9th is a check digit or X. North American and Chinese VINs have one; many European VINs do not.
Valid
1M8GDM9AXKP042788
Invalid
1M8GDM9AXKP042789 (last character changed)

Change the last character and the field turns red; submitting is blocked with the browser's own message. The field is required, so an empty field is invalid too. For an optional field, remove required: browsers never test an empty value against the pattern.

The check catches any single wrong digit. Some schemes miss certain swaps of neighbours: Luhn misses 09 ↔ 90, barcodes miss swaps of digits that differ by 5. Generated by rexsum.
